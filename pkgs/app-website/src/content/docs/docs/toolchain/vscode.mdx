The Genotype extension adds syntax highlighting and document formatting for `.type` files, bracket matching and auto-closing, indentation, comment commands, and region folding.

Install it from:

- [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=nocorp.genotype)
- [Open VSX](https://open-vsx.org/extension/nocorp/genotype)

See corresponding marketplace pages for more information about the usage and the configuration details.
