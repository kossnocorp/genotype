## Output

Genotype has two output modes for TypeScript:

- [Package Mode](#package-output-mode): Genotype generates a ready-to-use npm package with `package.json`, package directory structure, and TypeScript files.
- [Modules Mode](#modules-output-mode): In modules mode, Genotype generates only TypeScript files in the specified output directory, as a part of a larger package.
