## Data Types

### Scalar Types

#### Numeric Types

There are several numeric types available in Genotype, ranging in specificity and size.

The basic numeric types are:

- `number`: a floating-point number, similar to JavaScript.
- `int`: a signed integer, similar to Python's `int`.
- `float`: a floating-point number, similar to Python's `float`.

Genotype also supports specifying the size of numeric types, mirroring Rust's numeric types:

| Type    | Size                                                           |
| ------- | -------------------------------------------------------------- |
| `i8`    | 8-bit signed integer                                           |
| `i16`   | 16-bit signed integer                                          |
| `i32`   | 32-bit signed integer                                          |
| `i64`   | 64-bit signed integer                                          |
| `isize` | Signed integer with the same size as the target architecture   |
| `u8`    | 8-bit unsigned integer                                         |
| `u16`   | 16-bit unsigned integer                                        |
| `u32`   | 32-bit unsigned integer                                        |
| `u64`   | 64-bit unsigned integer                                        |
| `usize` | Unsigned integer with the same size as the target architecture |
| `f32`   | 32-bit floating-point number                                   |
| `f64`   | 64-bit floating-point number                                   |

When compiling, Genotype will automatically select the appropriate numeric type based on the target language and its type system:

```type
Number: number
Int: int
Float: float

Int8: i8
Int16: i16
Int32: i32
Int64: i64
Int128: i128
IntSize: isize

IntU8: u8
IntU16: u16
IntU32: u32
IntU64: u64
IntU128: u128
IntUSize: usize

Float32: f32
Float64: f64
```
